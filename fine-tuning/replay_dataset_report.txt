TRAINING STRATEGY:
--------------------------------------------------------------------------------
During each training step:
  1. Sample 50% shorts triplets (learn new shorts classification)
  2. Sample 50% base triplets (replay base model knowledge)
  3. Forward pass through LoRA-fine-tuned model
  4. Compute loss: alpha * shorts_loss + (1-alpha) * base_loss
     (alpha=0.5 for balanced learning)
  5. Backprop through LoRA layers only (base model frozen)

EXPECTED OUTCOMES:
--------------------------------------------------------------------------------
1. Shorts classification accuracy: +20-30% (new capability)
2. Shirts/pants/dresses performance: Maintained (replay prevents forgetting)
3. Model weights: +5-10% change in LoRA adapters (safety threshold)
4. No catastrophic forgetting due to 50/50 mixed training
