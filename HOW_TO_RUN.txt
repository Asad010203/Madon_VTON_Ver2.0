================================================================

4. STOP CONTAINERS / HALT BILLING
================================================================

Containers auto-stop after ~5 min of no requests. To force-stop right now:

Option A - Stop specific app (kills its containers but keeps app deployed):

    .\.venv\Scripts\python.exe -m modal app stop idm-vton

Option B - Stop a specific container:

    .\.venv\Scripts\python.exe -m modal container list
    .\.venv\Scripts\python.exe -m modal container stop <CONTAINER_ID>

After stopping:
  * App is still deployed - you can run test_idm.py again without redeploying
  * No compute charges accrue while stopped
  * Only volume storage keeps costing ~$1.20/month for both volumes


================================================================
5. DESTROY / DELETE (nuclear option — only when done permanently)
================================================================

Delete the app (undeploy — you'd have to redeploy to use again):

    .\.venv\Scripts\python.exe -m modal app stop idm-vton
    .\.venv\Scripts\python.exe -m modal app delete idm-vton

Delete the weight volumes (WARNING: will need to re-download 28+34 GB):

    .\.venv\Scripts\python.exe -m modal volume delete idm-vton-weights
    .\.venv\Scripts\python.exe -m modal volume delete leffa-weights

DO NOT delete volumes unless you're sure - re-downloading takes ~10 min
and costs a little. Volumes only cost ~$1.20/month combined to keep.

6. TROUBLESHOOTING
================================================================

Error: "The term '.\.venv\Scripts\python.exe' is not recognized"
    You're not in D:\madon\IDM-VTON folder. Run:  cd "D:\madon\IDM-VTON"

Error: "charmap codec can't encode"
    You forgot to set encoding. Run:  $env:PYTHONIOENCODING = "utf-8"

Error: "No module named 'modal'"
    Setup didn't complete. Re-run Section 0.

Error: "external shut-down" during deploy
    Transient Modal infra issue. Just retry the deploy command.

Function errors (SIGSEGV, import errors, etc.):
    Read IDM_VTON_SESSION_NOTES.md - every known error and fix is documented.

Slow test_idm.py (>2 min):
    First call cold-starts the container - normal.
    If every call is slow, container is stopping between calls. That's fine.

Modal dashboard for everything:
    https://modal.com/apps/abdullahsaleem75911
